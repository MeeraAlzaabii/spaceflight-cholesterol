# spaceflight-cholesterol

A reproducible reanalysis of NASA GLDS-241 mouse skin RNA-seq: spaceflight vs ground control

Author: Meera Alzaabi ([ORCID 0009-0003-8850-5731](https://orcid.org/0009-0003-8850-5731)),
with Razan Amer, Shamsa Aladawi, Hessa Almesafri, Meznah Alhmoudi and Radyah Fiza.

## About the project

Does spaceflight change gene expression in mouse skin, and are cholesterol-metabolism genes affected? Starting from GeneLab's counts table, the analysis runs PCA and clustering, differential expression with DESeq2, and KEGG pathway analysis.

It is based on the authors' final project for BMED 430 (Khalifa University,2024), made reproducible for CBIO7501 (MBZUAI, 2026). It covers the analysis from the counts table onward; read QC and alignment are not included. The original course report was not published.

## Reproduce the results

You need [Pixi](https://pixi.prefix.dev/latest/) and an internet connection. Then, from this folder:

```bash
pixi install --locked # builds the exact environment recorded in pixi.lock
pixi run reproduce    # downloads the raw data and rebuilds every result
```

`pixi run reproduce` runs `pixi run download` (data and KEGG gene sets),
`pixi run run-snakemake` (the four analysis steps) and `pixi run report`
(the Quarto report). To change a setting, edit `config/config.yaml` and run it again; `pixi run clean` deletes everything it made except the raw data.

`pixi run reproduce` must work on a fresh clone of this repository.
A GitHub Action (`.github/workflows/reproduce.yml`) checks that on every push.

## Hardware

A laptop is enough. Measured on a Windows laptop (WSL Ubuntu, one core): the full run takes about 1.5 minutes and peaks at about 1 GB of RAM. Disk: 3.3 GB for the Pixi environment (the first `pixi install` takes several minutes) and under 50 MB for data and results.

Tested on Linux: WSL Ubuntu on Windows, and Ubuntu on GitHub Actions.
`pixi.lock` also covers macOS (Intel and Apple silicon), but it has not been tested there. On Windows, use WSL (Ubuntu): the Bioconductor packages come from bioconda, which has no Windows builds.

## Expected outputs

- `reports/report.html`: the report; every number in it is computed when it renders.
- `results/figures/`: PCA, clustering, MA and volcano plots, heatmap, KEGG plots.
- `results/tables/`: DESeq2 results, significant genes, PCA, clusters, pathways.
- `results/logs/`: a log and a package-version file for each step.

Main results: PC1 explains about 32% of the variance; 4 genes are significant (padj < 0.05, |log2 fold change| > 1), including Angptl8, up in spaceflight; the enriched KEGG pathway is Cholesterol metabolism. The 2024 report found 42 significant genes; GeneLab has since reprocessed the data (see `docs/decisions.md`).

## What is where

| Folder | What goes in it | Rule |
|--------|-----------------|------|
| `data/raw/` | GLDS-241 tables and KEGG gene sets, as downloaded | Read-only. Downloaded by script. Not committed. |
| `data/processed/` | Counts with sample labels, DESeq2 object | Regenerated by code. Not committed. |
| `metadata/` | Data sources and checksums | Small text files, committed. |
| `scripts/` | Download scripts and the four R analysis steps | Committed. |
| `config/` | `config.yaml` with every analysis setting | Committed. |
| `workflow/` | `Snakefile` that runs the analysis steps | Committed. |
| `reports/` | `report.qmd`, the Quarto report | Source committed, rendered HTML not. |
| `results/` | Figures, tables, logs made by the code | Regenerated. Not committed. |
| `docs/` | `decisions.md`: changes from the original code | Committed. |
| `containers/` | Dockerfile built from `pixi.lock` | Committed. |

Each folder has its own `README.md` with more detail.

## Data

GeneLab dataset GLDS-241 (OSD-241), *Transcriptional analysis of femoral skin from mice flown on the RR-5 mission*, NASA Open Science Data Repository, doi:[10.26030/gfsz-c144](https://doi.org/10.26030/gfsz-c144): 9 spaceflight and 10 ground-control mice, RSEM counts processed by GeneLab. NASA data are public domain. KEGG pathway data come from <https://www.kegg.jp> under KEGG's own terms and are downloaded at run time, not redistributed here.

`pixi run download` fetches the files; sources and checksums are in `metadata/`.
